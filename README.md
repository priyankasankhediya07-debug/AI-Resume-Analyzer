# AI Resume Analyzer

## 📌 Overview
AI Resume Analyzer is a web application that analyzes resumes and provides ATS score, skill analysis, and AI-powered suggestions.

## ✨ Features
- Upload Resume (PDF/DOC/DOCX)
- ATS Score Analysis
- Skill Detection
- Resume Suggestions
- Clean User Interface
- Dark Mode

## 🛠 Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
